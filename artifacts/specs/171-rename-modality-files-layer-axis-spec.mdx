## Context

Promoted from [frame #171](../frames/171-rename-modality-files-layer-axis-frame.mdx).

Issue #170 restructured `src/voicecli/` into layer sub-packages. Some files retained modality-tagged names (`stt_*`, `tts_*`) as historical residuals. This spec tracks their rename to layer-axis names, plus import and documentation updates.

**Scope update from #170:** The issue body lists `src/voicecli/nats_stt_client.py` → `src/voicecli/nats_transcribe_client.py`. However, #170 already moved this file to `src/voicecli/adapters/nats/stt_client.py`. The rename is adjusted to keep it in the correct layer package: `src/voicecli/adapters/nats/stt_client.py` → `src/voicecli/adapters/nats/transcribe_client.py`.

## Goal

All modality-tagged filenames in `src/voicecli/` are renamed to layer-axis names, with all internal imports, docs, and external callers updated atomically in a single PR.

## Users

- **Primary:** Developers maintaining voiceCLI
- **Secondary:** lyra hub-spoke agents and deploy scripts importing voiceCLI modules

## Expected Behavior

1. Each file in the rename table is moved to its proposed name via `git mv` (preserving history).
2. All `from voicecli... import ...` statements referencing old module names are updated to new names.
3. All `__init__.py` lazy-loading entries (e.g., `adapters/nats/__init__.py`) are updated.
4. All documentation references (`.axial-allowlist`, ADRs, setup guides) are updated.
5. External callers (lyra, deploy scripts) are verified and updated if needed.
6. `ruff check .`, `ruff format .`, `pyright` all pass after renames.
